# @moncface/colophon

**Colophon** is a convention for attaching a machine-readable *colophon* —
authorship, license, and provenance metadata — to single-file distributed
artifacts (such as published Claude artifacts), where no platform-level
author field, index, or license slot exists.

The name follows the [IndieWeb colophon](https://indieweb.org/colophon)
practice: a page describing how a thing was made. Colophon makes that
practice machine-readable.
