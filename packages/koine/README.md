# @moncface/koine

**Koine** is a common wrapper format for LLM-mediated data interchange:
a small, frontmatter-compatible `meta` layer plus a `kind:`-declared
payload. It targets domains where multiple platforms express the same
intent in different notations and round-trips always lose information.
